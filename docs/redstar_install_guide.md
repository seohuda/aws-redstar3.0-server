# 붉은별 3.0 서버 (Red Star OS 3.0 Server) 단계별 설치 가이드

이 가이드는 VNC 콘솔을 통해 Red Star OS 3.0 Server를 설치하는 GUI 절차와 2-ISO 미디어 전환 과정을 설명합니다.

---

## 1. 사전 준비 및 콘솔 연결

1. 인프라 배포 및 ISO 업로드가 완료되면 VM을 생성합니다.
   ```bash
   ./scripts/create-redstar-vm.sh
   ```
2. 로컬 PC에서 EC2로 SSH VNC 터널을 생성합니다.
   ```bash
   ssh -i infra/redstar-key.pem -N -L 5900:127.0.0.1:5900 ubuntu@<EC2_PUBLIC_IP>
   ```
3. 로컬 VNC Viewer(TigerVNC, RealVNC, Remmina 등)를 실행하여 다음 주소로 접속합니다:
   ```
   127.0.0.1:5900
   ```

---

## 2. Red Star OS 3.0 설치 화면 진행 절차

### 1) 부팅 화면 (Boot Loader)
- VNC 접속 시 첫 화면에 붉은별 운영체제 부트로더 화면이 표시됩니다.
- **"붉은별 3.0 서버 설치" (또는 Install Red Star Server)** 항목을 선택하고 `Enter`를 누릅니다.

### 2) 설치 언어 및 키보드
- 기본 언어는 **조선말 (한국어)**로 설정되어 있습니다.
- 키보드 배치는 한국어(101/104키 호환)를 선택합니다.

### 3) 저장 장치 파티션 설정
- 대상 디스크: `/dev/vda` (40GB 가상 드라이브)
- 파티션 옵션:
  - **"모든 공간 사용 및 자동 파티션 생성"**을 권장합니다.
  - 경고 창이 나타나면 **"디스크 쓰기(초기화)"**를 선택합니다.
  - ext4 파일시스템으로 루트(`/`), 스왑(`/swap`), 부트(`/boot`)가 자동 할당됩니다.

### 4) 네트워크 및 호스트명
- 네트워크 장치: `eth0` (Intel e1000)
- DHCP를 통해 libvirt 가상 네트워크(`192.168.122.x`) IP를 자동 수신하도록 설정합니다.
- 호스트명: 기본값 또는 `redstar-server` 입력.

### 5) 시계 및 시간대 (타임존)
- 평양 시간(UTC+9 또는 UTC+8:30) 또는 서울 시간(UTC+9)으로 설정합니다.

### 6) 관리자(root) 암호 설정
- 관리자 암호를 지정합니다. (예: 안전한 패스워드 설정 후 메모)

### 7) 소프트웨어 패키지 선택
- 서버 목적에 따라 설치 그룹을 선택합니다:
  - **기본 서버 (Web Server, FTP, SSH 포함)**
  - 또는 그래픽 환경(KDE GUI) 포함 패키지 선택.

---

## 3. 핵심: 미디어 교체 (2nd ISO Hot-Swap)

1. 패키지 설치가 시작되기 전 또는 진행 도중, 화면에 다음과 같은 팝업 창이 표시됩니다:
   > **"두번째 설치원반을 넣어주십시오"** (또는 Insert CD/DVD 2)
2. 이 대화 상자가 나타나면 **확인을 누르지 않은 상태에서**, 로컬 터미널에서 다음 스크립트를 실행합니다:
   ```bash
   ./scripts/switch-to-install-iso.sh
   ```
   - 스크립트가 VM XML에서 CD-ROM 드라이브(`hdc`)를 찾아 `redstar-install.iso`를 마운트합니다.
3. 스크립트 완료 메시지가 출력되면, VNC 화면의 **[확인]** 버튼을 클릭합니다.
4. 패키지 복사 및 시스템 설치가 정상적으로 계속 진행됩니다.

---

## 4. 설치 완료 및 사후 설정

1. 모든 패키지 복사가 완료되면 **"설치가 성공적으로 끝났습니다"** 화면이 나타납니다.
2. 재부팅 버튼을 누르기 전, CD-ROM 미디어를 배출합니다:
   ```bash
   ./scripts/eject-redstar-iso.sh
   ```
3. VNC 화면에서 **[재시동(Reboot)]** 버튼을 클릭합니다.
4. 이제 가상 머신이 qcow2 가상 디스크 단독으로 부팅되며, 붉은별 3.0 서버 데스크톱 또는 쉘 콘솔로 로그인할 수 있습니다.
5. 웹 서비스 활성화:
   ```bash
   # Red Star OS 내부 터미널
   service httpd start
   chkconfig httpd on
   ```
   - 이제 웹 브라우저에서 `http://<EC2_PUBLIC_IP>`로 접속하면 Red Star OS 웹페이지가 표시됩니다.
